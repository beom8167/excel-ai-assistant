# Excel AI Assistant — AI Version

사용자의 자연어 요청을 AI가 Excel 작업 계획으로 변환한 뒤, 사용자가 승인하면 브라우저에서 실제 Excel 파일에 적용하는 MVP입니다.

## 현재 지원 기능

AI가 다음 작업으로 변환할 수 있습니다.

- 계산 열 생성 및 수식 채우기
  - 예: `목표금액과 실적금액을 비교해서 달성률 열 만들어줘`
- SUM / AVERAGE / COUNT / COUNTA / MAX / MIN
  - 예: `판매금액 합계를 마지막 행 아래에 넣어줘`
- 특정 셀 수식 입력
- 특정 셀 값 입력
- 행 사이 빈 행 삽입
  - 예: `1~10행 사이마다 빈 행 하나씩 추가해줘`
- 헤더 이름을 보고 열 위치 추론

## 구조

- `index.html` — 모바일/PC 프론트엔드, Excel 업로드·미리보기·실제 수정
- `netlify/functions/ai.js` — OpenAI Responses API 호출
- `netlify.toml` — Netlify 배포 설정

Excel 파일 자체는 프론트엔드 브라우저에서 처리합니다. AI 요청 시에는 시트 이름, 사용 범위, 행/열 수, 최대 12행 × 18열의 샘플 데이터가 서버 함수로 전달됩니다.

## 배포 절차

### 1. Netlify에 프로젝트 배포

서버 함수가 포함되어 있으므로 단순 HTML 파일 열기만으로는 AI 기능이 동작하지 않습니다.
GitHub 저장소에 이 폴더를 올린 뒤 Netlify에서 해당 저장소를 연결하는 방식이 가장 간단합니다.

### 2. OpenAI API Key 환경변수 등록

Netlify 사이트 설정에서 환경변수를 추가합니다.

- Key: `OPENAI_API_KEY`
- Value: 본인의 OpenAI API Key

선택 사항:

- Key: `OPENAI_MODEL`
- Value: `gpt-6-luna`

API 키를 `index.html` 또는 JavaScript 프론트엔드에 직접 적지 마세요.

### 3. 재배포

환경변수를 등록한 뒤 재배포합니다.

## 테스트 문장

- `목표금액과 실적금액을 비교해서 오른쪽에 달성률 열을 만들어줘. 0으로 나누는 오류도 처리해줘.`
- `판매금액 열의 합계를 데이터 마지막 행 바로 아래에 넣어줘.`
- `목표금액보다 실적금액이 크거나 같으면 달성, 아니면 미달로 표시하는 판정 열을 만들어줘.`
- `1~10행 사이마다 빈 행 하나씩 추가해줘.`

## MVP 제한

- 실제 Excel 계산 엔진은 브라우저에 포함하지 않았습니다. 수식은 파일에 기록되고, 다운로드한 파일을 Microsoft Excel에서 열면 계산 결과가 갱신됩니다.
- VBA/매크로, 피벗, 차트, 복잡한 스타일 편집은 현재 범위에서 제외했습니다.
- AI가 제안한 작업은 반드시 화면의 작업 계획을 확인하고 `계획 적용`을 눌러야 반영됩니다.
